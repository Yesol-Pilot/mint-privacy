성벽수비 블록전 개인정보 처리방침

시행일: 2026년 7월 29일

이 문서는 ONE Store에서 배포하는 Android 버전에만 적용됩니다.

1. 운영자 정보

  • 운영자: Neo Genesis
  • 앱: 성벽수비 블록전
  • 문의: help@neogenesis.app

2. 개인정보 처리

현재 ONE Store Android 버전은 이름, 연락처, 계정, 결제정보, 정밀 위치정보처럼 이용자를 직접 식별하는 정보를 입력받거나 운영자 서버로 전송하지 않습니다. 별도 회원가입과 로그인도 제공하지 않습니다.

3. 기기에 저장되는 게임 데이터

다음 정보는 게임 진행을 위해 이용자의 기기에만 저장될 수 있습니다.

  • 라운드와 최고 기록, 코인, 보유 유닛과 강화 상태
  • 출석과 일일 미션 진행, 무료 소환 횟수
  • 사운드 설정과 게임 진행 상태

4. 광고, 분석 및 결제

현재 ONE Store Android 버전에는 광고 SDK와 광고 ID 권한을 포함하지 않습니다. 외부 분석 SDK, 실제 유료 결제, 유료 확률형 아이템도 제공하지 않습니다. 게임의 무작위 소환은 무료 또는 게임 안에서 획득한 가상 재화만 사용하며, 확률과 천장 횟수를 게임 화면에 공개합니다.

5. 보유 기간과 삭제

게임 데이터는 이용자의 기기에 보관됩니다. 앱 데이터 삭제 또는 앱 제거를 통해 삭제할 수 있습니다.

6. 아동의 개인정보

앱은 아동을 포함한 이용자에게 개인정보 입력을 요구하지 않습니다. 기능이나 데이터 처리 방식이 변경되면 이 방침과 스토어 신고 내용을 함께 갱신합니다.

7. 변경

광고, 분석, 로그인, 결제, 서버 저장 기능을 추가하는 경우 적용 전에 이 방침을 갱신하고 변경된 시행일을 표시합니다.
